How to read this

Scores are guesses used; a failed game counts as 7. Lower is better. The twenty games are stratified by how hard the language model found them, so the set deliberately includes one it solved in two and one it failed outright — a random twenty would be almost all threes and fours and would separate nothing.

The model rows are not re-simulated for this page. They are the exact per-game records the published paired tests were computed from, so nothing here can disagree with the reported numbers. The classical solvers had no per-game record on disk, so they were replayed against these same answers through the project's own play_game.

Twenty games is not enough to separate these solvers. The standard error on a 20-game mean is roughly 0.2 guesses, which is wider than most of the gaps in the table. The Mean, 246 column is the real measurement; the 20-game column is there so your own score has something to sit beside. Treat a win over the model on twenty games as a fun result, not a finding.

The one column that is a genuine finding: the 0.5B model at 3.7642 sits between classical frequency and classical random, and 0.32 behind classical entropy — a gap that four separate attempts failed to close.
